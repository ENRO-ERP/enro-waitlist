# ENRO waitlist website

An AI-built draft of the ENRO waitlist website. It is not final yet; use it as a starting point to try, improve and develop further.

## Download and run

Download **ENRO-Waitlist-Website.zip** from this repository and extract it. Inside the extracted folder, run `npm start` with Node.js 22 or later, then open http://127.0.0.1:4180. Works on macOS and Windows. No dependency installation or build step is needed.

## Everything included

The archive contains all 18 project files: frontend HTML/CSS/JavaScript, Node signup backend, tests, original clay artwork and prompts, optimized website images, ENRO dashboard image, desktop/mobile previews, and setup/deployment instructions.

Signups save privately to a local data file. Public hosting and automated emails are not set up. Read the included README before deploying.
